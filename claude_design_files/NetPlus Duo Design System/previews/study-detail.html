Networking Concepts

1.1 The Seven Layers

The OSI model, encapsulation, and how data moves layer by layer.

OSI Model — All 7 Layers

Layer #NamePDUKey Protocols / Devices
7ApplicationDataHTTP, HTTPS, FTP, SSH, DNS, SMTP, SNMP, Telnet
4TransportSegment / DatagramTCP (reliable), UDP (fast) — port numbers live here
3NetworkPacketIP, ICMP, OSPF, BGP — Router operates here
2Data LinkFrameEthernet, 802.11 Wi-Fi, ARP — Switch / MAC addresses
1PhysicalBitHubs, cables, repeaters, NICs — raw electrical/optical signals
  • Router = Layer 3. Switch = Layer 2. Hub = Layer 1.
  • TCP/UDP port numbers live at Layer 4.

OSI Mnemonic

Please Do Not Throw Sausage Pizza Away 7 6 5 4 3 2 1 (Reversed — bottom to top: All People Seem To Need Data Processing)

  • Top-down (app to wire): Please Do Not Throw Sausage Pizza Away
  • Bottom-up (wire to app): All People Seem To Need Data Processing

Encapsulation & PDU Names

When data travels DOWN the OSI stack, each layer ADDS a header (and sometimes a trailer). This is encapsulation.

  • Data → Segment → Packet → Frame → Bits (DSPFB)
  • De-encapsulation: reverse process on the receiving end.
