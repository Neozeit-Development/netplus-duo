// OBJECTIVE · 2.3.4
Convert between CIDR notation and dotted-decimal masks
// NETWORK IMPLEMENTATION · D02
34 % MASTERED
// 8 / 24 CORRECT IN PROGRESS
// CORE CONCEPTS
CIDR CLASSLESS INTER-DOMAIN ROUTING
A prefix notation where /N indicates how many bits are used for the network portion. The remaining 32−N bits identify hosts.
// FORMULA
HOSTS = 2(32−N) − 2
−2 removes network & broadcast addrs
DOTTED-DECIMAL
Four octets of 8 bits each, written as decimal integers 0–255, separated by dots. A contiguous block of 1s from the left marks the network; 0s to the right mark host bits.
// EXAMPLE
/24
↔
// MASK
255.255.255.0
↔
// HOSTS
254
// CIDR QUICK-REF TABLE

// MNEMONIC · THE MAGIC NUMBER METHOD
1
// FIND THE INTERESTING OCTET
Divide CIDR prefix by 8. The quotient (0–3) is the octet index. The remainder tells you which octet is "interesting."
/28 → 28 ÷ 8 = 3 r 4 → 4th octet
2
// MAGIC NUMBER
Subtract the interesting octet's mask value from 256. This is your block size, the subnet interval.
256 − 240 = 16  →  block size
3
// COUNT IN MULTIPLES
List subnets by counting up in that block size. The network addr is the start; broadcast is (next − 1).
.0   .16   .32   .48   .64   .80 …
4
// VERIFY HOST COUNT
Hosts = block size − 2. For /28: 16 − 2 = 14 usable hosts.
// EXAM TRAPS
Forgetting to subtract 2
Questions ask for usable hosts, not total addresses. Always subtract network + broadcast.
/31 and /32 are special cases
/31 = point-to-point (2 addrs, 0 hosts by rule). /32 = single host route, loopback.
Confusing /16 mask value
255.255.0.0 ≠ 255.0.0.0. /16 fills only the first two octets. A common trap in multiple choice.
